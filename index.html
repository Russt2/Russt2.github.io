Fukary Exchange

A private exchange for approved requests, responses and receipts between an owner and participating AI assistants.

What it does

Fukary Exchange is operated by Russt for personal use. It uses Google Drive to hold selected exchange files and comments, helping the owner and AI assistants coordinate a bounded task and confirm which response was received.

The current workflow is manually approved. A small connectivity pilot has been completed; continuous operation and scheduled exchanges are not enabled. There is no public sign-up service.

Why Google Drive access is requested

The local application requests the drive.file permission: access to files it creates or files specifically made available to it. It uses authorized file content, comments and metadata to carry the exchange, and the account email address to check that the correct owner is connected.

This permission is not full-Drive access. It is also not a guarantee that every other connected assistant has the same narrow access. Each participating service has its own permissions and data handling.

Google authorization is performed separately through the owner’s desktop application. This informational website does not sign users in, request passwords, receive OAuth callbacks or provide access to private exchange files.

Privacy and owner control

Approved exchange content can be processed by Google and participating AI-service providers. Local records and private backups may also retain copies. Private file sharing does not mean end-to-end secrecy or automatic deletion from all providers.

Read the Fukary Exchange Privacy Policy for the data categories, processing, retention and deletion limitations.

The exchange does not grant assistants permission to trade, publish private materials, change credentials or start recurring work. Those actions require separate owner approval.
